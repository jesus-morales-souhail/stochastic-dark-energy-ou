# theory/ — theory-programme notes

These notes set out the theoretical framing behind the residual analysis: unimodular / SDiff gravity, the smoothness of the vacuum, the fundamental-versus-emergent relaxation picture, the neutrino–dark-energy degeneracy, and a forecast protocol for Euclid.

**They are not part of the preprint's claim set (C1–C7 in [`../manuscript/CLAIMS.md`](../manuscript/CLAIMS.md)).** Do not cite them as DESI results. Non-claims N3 (no unique proof of unimodular / SDiff gravity) and N8 (no bound on \(\sum m_\nu\)) apply here.
